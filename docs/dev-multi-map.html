How the 48-unit lanes were tested

November 14–15, 2026

Separate client identities, eight hours on loopback and a physical LAN follow-up.

Define the multi-map test

A dedicated server can load additional BSPs in separate contexts at fixed offsets. The fixture used revised teleport lanes with a 48-unit perpendicular separation and repeatedly moved paired clients across the boundary. The harness checked each client’s world and isolation while tracking transitions, reconnections, telefrags and flood drops.

Make each local client identifiable

The earlier long run reached 58 paired rounds before a later activation stalled. A second client was classified as a reconnect and reused the other client’s server slot even though its UDP source port was different. The successor pinned distinct, stable UDP and protocol ports for the two clients and verified that each pair occupied separate server slots.

Complete the loopback and LAN runs

The eight-hour loopback run completed 699 paired rounds and 698 checked disconnects, with 16,760 isolation samples. The two lanes recorded 8,261 and 8,141 transitions. A physical two-machine LAN follow-up completed three paired rounds, 56 isolation samples and 56 checks at the authored 48-unit positions. The two clients completed 28 and 27 transitions. Both runs recorded zero telefrags and zero flood drops.

Try the small example

Relay Rooms includes a simpler map rotation and an additional static BSP at an offset. Both configs loaded on a headless server with networking disabled. The sample offers an editable starting point. A separate rendered local run verified both Relay Hall pads with scripted forward movement. Internet route qualification is still open.
