# Release notes

## 0.1.0 · 2026-11-22

- Added separate Q26, Chaos Circuits and Assault Knights hubs.
- Added original terrain and route illustrations and five development articles with the evidence and limits for each result.
- Added Relay Hall and Relay Annex in a small PK3, plus editable map sources, original shader tiles, local config examples and a rebuild guide.
- Verified both maps with BSP, visibility and lighting compiles and recorded their SHA-256 hashes. An isolated dedicated server verified map rotation and the additional static subworld. A rendered Windows OpenGL run activated both Relay Hall teleport pads with scripted forward movement and verified their opposite-bay destinations.
- Included a licence and credit statement. The release contains the showcase and its original examples.
